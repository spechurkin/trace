# Пользовательские темы

[README](../README.ru.md) · [English](themes.md)

Откройте **Настройки → Оформление → Открыть папку тем**. Создайте вложенную папку с любым именем и добавьте в неё файлы
своей темы. После добавления или редактирования нажмите **Перезагрузить темы**.

Папка `themes` находится рядом с установленным исполняемым файлом. В переносимой Windows-версии она расположена рядом с
переносимым EXE, в Linux AppImage — рядом с AppImage. На macOS папка находится рядом с `Trace.app`, вне пакета
приложения. При разработке используется `themes` в корне проекта. Для папки нужны права записи; кнопка открытия также
создаёт её при необходимости. Полный путь отображается в настройках.

Каждая тема содержит `theme.json`, таблицу стилей CSS и необходимые изображения или шрифты. Файлы тем хранятся вне
архива приложения. Windows-установщик сохраняет `themes` при замене и удалении приложения. При переносе приложения
перенесите и эту папку.

**Clubs** — готовая светлая тема с исходным дизайном Clubs: зелёные акценты, тёмная зелёная панель навигации и мягкие
бумажные фоны. Windows-установщик устанавливает её в `themes/clubs` до первого запуска. В переносимой версии и на других
платформах пакет создаётся при запуске, если папки ещё нет. Существующие папки не перезаписываются. Выберите **Clubs** в
настройках. Исходное оформление Следа остаётся доступно как **След — Оригинальная**.

## Описание темы

Файл `theme.json` описывает CSS-тему:

```json
{
  "format": "clubs/theme",
  "api_version": 1,
  "name": "Моя тема",
  "mode": "dark",
  "stylesheet": "style.css"
}
```

`format` и `api_version` определяют общий с Clubs API тем; сохраняйте `clubs/theme` для совместимости пакетов. `name` —
название в списке; необязательное поле `description` —
описание. `mode` принимает `dark` или `light`. `stylesheet` — относительный путь к CSS внутри папки темы; разделитель
каталогов — `/`.

Для нескольких вариантов в одной папке замените `mode` на `variants`:

```json
"variants": [
{"id": "night", "name": "Моя тема — Ночь", "mode": "dark"
},
{
"id": "day", "name": "Моя тема — День", "mode": "light"}
]
```

Идентификаторы вариантов должны быть уникальными и постоянными. Каждый вариант появляется отдельным пунктом. Выбор
запоминается по имени папки и идентификатору варианта; их переименование делает сохранённую тему недоступной.

## Стили

При применении темы приложение устанавливает атрибуты на `<html>`:

- `data-theme="custom"`;
- `data-theme-mode="dark"` или `"light"`;
- `data-theme-id` с именем папки;
- `data-theme-variant` с идентификатором варианта, если он есть.

Определяйте палитру через `:root[data-theme='custom']`. Для отдельных режимов и вариантов можно добавлять свои
селекторы:

```css
:root[data-theme='custom'] {
  --theme-accent: #8ac6ad;
  --theme-accent-ink: #16251e;
  --theme-bg: #18231e;
  --theme-panel: #24352b;
  --theme-text: #edf4ec;
  --theme-muted: #b5c5b7;
}

:root[data-theme='custom'][data-theme-variant='day'] {
  --theme-bg: #f7f8f4;
  --theme-panel: #ffffff;
  --theme-text: #2c3f36;
  --theme-muted: #657568;
}
```

Доступны
переменные: `--theme-accent`, `--theme-accent-ink`, `--theme-bg`, `--theme-panel`, `--theme-panel-alt`, `--theme-input`, `--theme-text`, `--theme-muted`, `--theme-faint`, `--theme-line`, `--theme-hover`, `--theme-canvas`, `--theme-active`, `--theme-shadow`, `--theme-font`.
Для остальных значений используется палитра выбранного режима по умолчанию. Она применяется к панелям, кнопкам, полям,
диалогам и видимой схеме, не изменяя записи библиотеки.

Через CSS можно оформлять существующие
компоненты: `.rail`, `.topbar`, `.sidebar`, `.canvas`, `.inspector`, `.settings-card`, `.character-card`, `.modal`.
Иллюстрации встроенных тем к пользовательским темам не добавляются.

Изображения, шрифты и дополнительные CSS подключаются относительно таблицы
стилей: `url('./images/paper.svg')`, `url('./fonts/story.woff2')`, `@import './palette.css';`. Все ресурсы должны
оставаться внутри папки своей темы. Поддерживаются CSS, SVG, PNG, JPEG, WebP, GIF, WOFF, WOFF2, TTF и OTF. Ограничение
исходных файлов темы — 2 МиБ, изображений и шрифтов — 32 МиБ. Темы используют CSS; точки входа JavaScript/TSX нет. Для
переноса темы Maploom нужно адаптировать описание и селекторы к Clubs.

## Установка и удаление

Папка `themes` исключена из очистки Windows-установщика. Замена и удаление приложения убирают его файлы, сохраняя все
папки тем. Опция удаления данных приложения также не затрагивает эту папку. Файлы AppImage и пакеты приложения macOS
заменяются отдельно от соседней папки `themes`; пользовательские файлы тем не входят в состав Linux DEB-пакета.

Сценарий `scripts/check-themes-windows.ps1` проверяет отдельную установку NSIS, переустановку той же версии, режим
обновления, удаление и установку после удаления, сравнивая SHA-256 всех файлов тем. Установщик для проверки нужно
собрать внутри `.test-data` с `appId=studio.trace.theme-lifecycle-test`, `productName=TraceThemeLifecycleTest`, без
ярлыков и запуска после установки. Сценарий отклоняет другие названия продукта и существующую тестовую установку.
Проверки жизненного цикла установщиков macOS/Linux выполняются отдельно от этого Windows-теста.

## Перезагрузка и недоступные файлы

Кнопка **Перезагрузить темы** перечитывает папку и повторно применяет выбранную таблицу стилей, включая изменения
локальных ресурсов. Папка также сканируется при запуске. Перезапуск после редактирования не требуется.

Некорректные пакеты отображаются в разделе **Ошибки загрузки тем**; исправные темы остаются доступны. Если выбранная
папка или вариант исчезли, используется оригинальное оформление, а выбор сохраняется. Восстановите файлы и перезагрузите
темы, чтобы вернуть его, либо выберите другую тему. При ошибке загрузки основной таблицы стилей настройки показывают
сообщение и включают оригинальное оформление. Ошибки отдельных изображений, шрифтов и CSS-импортов обрабатываются
браузером и не делают описание темы недействительным.
